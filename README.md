# 人生模拟器：美好人生叙事之旅

一款融合 AI 叙事生成、积极心理学与叙事疗法理念的互动人生模拟游戏。玩家通过一次次选择体验虚拟人生，在跌宕起伏的故事中觉察自身情绪、重构认知，并获得正向心理引导。

> **重要声明**：本游戏旨在提供娱乐与心理自助体验，不能替代专业心理咨询或医疗诊断。如你有严重心理困扰，请及时寻求专业帮助。

## 核心理念

- **AI 动态叙事**：每一次选择都会触发大语言模型实时生成贴合玩家状态的故事片段，避免重复与模板化。
- **积极心理学**：基于 PERMA 模型（积极情绪、投入、人际关系、意义、成就）设计事件与反馈。
- **叙事疗法**：通过"重写人生故事"帮助玩家从不同视角理解挫折，增强心理弹性。
- **正向引导**：在低谷事件中提供成长型思维提示，在爽文高光中强化自信与感恩。

## 玩法简介

1. **创建角色**：抽取天赋、分配属性，并可选择当前心情状态（完全匿名）。
2. **心理热身**：游戏开始前提供一次简短的积极心理引导。
3. **推进人生**：从出生开始，按年龄经历不同人生阶段。
4. **做出选择**：每个阶段遭遇事件，选择将影响属性、剧情与心理状态。
5. **AI 续写**：关键节点由 AI 根据上下文生成专属故事与后续选项。
6. **触发成长**：低谷后可能出现"顿悟事件"，将挫折转化为心理资本。
7. **查看结局**：人生终点生成双重总结——虚拟人生成就 + 心理成长报告。

## 技术栈

### 推荐生产级方案

| 层级 | 技术 | 说明 |
|---|---|---|
| 前端框架 | React 18 + TypeScript | 组件化、类型安全、生态成熟 |
| 构建工具 | Vite | 极速 HMR、现代打包 |
| 样式与 UI | Tailwind CSS + shadcn/ui | 原子化样式、可访问组件 |
| 动画 | Framer Motion | 流畅过渡与情感化动效 |
| 状态管理 | Zustand | 轻量、易用、可持久化 |
| 后端框架 | Node.js + Fastify / Express | 高性能 API 服务 |
| 接口协议 | tRPC 或 REST | 类型安全或通用性 |
| AI 生成 | OpenAI GPT-4 / Claude 3.5 Sonnet / 国产大模型 | 动态故事生成、心理引导 |
| 数据库 | PostgreSQL + Redis | 持久化用户数据、缓存会话 |
| 部署 | Docker + 云服务器 / Vercel | 前后端分离部署 |

### MVP 原型方案

如果你只想快速验证想法，可以先用以下轻量栈：

| 层级 | 技术 |

## 快速开始（MVP 方案）

```bash
# 克隆项目后安装依赖
npm install

# 复制环境变量模板并填写 AI API Key
cp .env.example .env

# 启动前端开发服务器
npm run dev

# 另开一个终端启动后端 API
npm run server
```

## 心理健康设计原则

- 所有事件避免极端负面渲染，低谷之后必须跟随后续成长选项。
- 提供"暂停与呼吸"按钮，玩家可随时退出或返回主界面。
- 结局报告强调努力、选择与成长，而非单一成功标准。
- 收集可选的匿名反馈，用于持续优化叙事方向。
