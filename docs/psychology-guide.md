# 人生模拟器：心理学配方指南

> **核心定位**：本指南为游戏设计提供心理学依据，确保玩家在娱乐中获得积极、安全、有意义的心理体验。
>
> **重要声明**：本游戏是心理自助与娱乐工具，不具备诊断或治疗功能。若玩家存在严重心理问题，应及时寻求精神科医生或注册心理咨询师的帮助。

## 一、理论基础

### 1.1 积极心理学（Positive Psychology）

**代表人物**：Martin Seligman

**核心观点**：心理学不仅要修复心理疾病，更要帮助人发展优势、体验幸福、实现潜能。

**游戏应用**：
- 引入 PERMA 幸福模型作为隐性评估维度：
  - **P**ositive emotion：高光事件、愉悦体验
  - **E**ngagement：心流事件、专注挑战
  - **R**elationships：亲情、友情、爱情、社会关系
  - **M**eaning：使命、价值观、利他行为
  - **A**ccomplishment：目标达成、技能成长
- 每个事件标注其促进的 PERMA 维度，结局以雷达图呈现。
- 设计"优势识别"环节，帮助玩家发现自身虚拟与现实中的品格优势。

### 1.2 认知行为疗法（Cognitive Behavioral Therapy, CBT）

**核心模型**：认知三角 —— 想法（Thoughts）→ 情绪（Feelings）→ 行为（Behaviors）相互影响。

**游戏应用**：
- **事件触发情境**（Activating Event）
- **自动化思维可视化**：在低谷事件中，展示角色可能的消极想法，并给玩家机会选择另一种解释。
- **认知重构选项**：
  - "这件事说明我一无是处"（灾难化）
  - "这是一次学习机会"（成长型思维）
  - "情况很糟，但我还能做点什么"（问题导向）
- **行为激活**：鼓励玩家选择具体行动，如"去跑步""和朋友聊聊""尝试一件小事"。
- **情绪标签化**：每次事件后让玩家选择当前情绪，提升情绪识别能力。

### 1.3 叙事疗法（Narrative Therapy）

**代表人物**：Michael White, David Epston

**核心观点**：人不是问题，问题才是问题。通过重写人生故事，人可以摆脱问题叙事，建构更有力量的自我认同。

**游戏应用**：
- **外化技术**：将挫折描述为"暂时来访的客人"，而非玩家身份。
  - 示例："失败这次敲了敲门，但你决定是否让它住下。"
- **独特结果**：在低谷中提醒玩家曾经克服困难的时刻。
- **重写人生**：结局时让玩家选择"这段人生最想保留的品质"，生成积极的自我叙事。
- **人生之书**：将整场游戏导出为可阅读的叙事文本，玩家可反复阅读。

### 1.4 接纳承诺疗法（Acceptance and Commitment Therapy, ACT）

**核心观点**：痛苦不可避免，但人可以学会接纳、活在当下、明确价值观并承诺行动。

**游戏应用**：
- **接纳选项**：有时最优选择不是"消灭痛苦"，而是"带着痛苦继续前行"。
- **价值观澄清**：在人生关键节点询问玩家"什么对你真正重要"。
- **承诺行动**：选择后展示该选择如何体现玩家的价值观。
- **解离技术**：当出现消极自我评价时，提供"把想法当作飘过天空的云"的隐喻。

### 1.5 意义疗法（Logotherapy）

**代表人物**：Viktor Frankl

**核心观点**：人类最根本的驱动力是寻找生命的意义，即使在痛苦中也能找到意义。

**游戏应用**：
- **意义事件**：志愿服务、照顾他人、创作、传承知识等。
- **苦难转化**：在重大挫折后，提供"这段经历教会了我什么"的反思。
- **结局报告**：不仅总结成就，更总结玩家在游戏中体现的价值与意义。

### 1.6 心理韧性（Psychological Resilience）

**核心观点**：韧性不是不经历逆境，而是在逆境中恢复并成长的能力。

**游戏应用**：
- 将"心理韧性"作为可培养属性。
- 设计"逆境后成长"（Post-Traumatic Growth）事件。
- 低谷事件后提供社会支持、意义重构、能力确认等恢复路径。

## 二、游戏事件设计心理学原则

### 2.1 事件结构模板

每个事件应包含：

```
[情境] → [自动化思维] → [情绪] → [行为选择] → [结果] → [心理提示]
```

示例：
- **情境**：高考失利。
- **自动化思维**："我的人生完了。"
- **情绪**：沮丧、焦虑。
- **行为选择**：
  - 复读一年（成长型）
  - 选择一所普通大学继续学习（接纳+行动）
  - 先工作再自考（另类路径）
- **结果**：根据选择调整属性与剧情。
- **心理提示**："一次考试不能定义你的人生，你接下来的选择才是关键。"

### 2.2 低谷事件设计原则

1. **必须附带成长出口**：每个低谷事件后，至少有一个选择能提升心理韧性或开启新路径。
2. **避免极端化**：不用"永远失败""一无是处"等绝对化表述。
3. **强调暂时性**：使用"暂时""目前""这次"等时间限定词。
4. **提供社会支持**：在低谷中安排朋友、家人、导师出现。
5. **控制节奏**：连续两个低谷事件后，必须插入中性或积极事件。

### 2.3 高光事件设计原则

1. **连接努力与结果**：高光不是纯运气，而是前期选择的自然结果。
2. **强化感恩**：高光事件中提示玩家感谢帮助过自己的人。
3. **避免自恋**：高光后提供"回馈他人""承担责任"等选项，促进意义感。
4. **防止空虚感**：连续高光后提供"这是否真的是你想要的"反思。

### 2.4 选择设计原则

每个选择代表一种心理策略：

| 选择类型 | 心理学基础 | 典型效果 |
|---|---|---|
| 稳妥型 | 风险规避、自我保护 | 稳定收益，心理安全感 |
| 冒险型 | 自我效能感、成长型思维 | 高收益或失败学习 |
| 关系型 | 依恋理论、社会支持 | 提升关系与归属感 |
| 成长型 | CBT 认知重构 | 提升韧性与长期能力 |
| 接纳型 | ACT 接纳与承诺 | 降低内耗，明确价值观 |
| 意义型 | Logotherapy | 提升意义感，即使短期吃亏 |

## 三、不同玩家状态的引导策略

### 3.1 玩家进入时情绪低落

- 开场降低事件冲突强度。
- 提供更多"关系型""接纳型"选项。
- 增加心理安全提示："如果你现在感到不适，可以随时退出。"
- 结局强化"你已经尽力了""你的价值不取决于成就"。

### 3.2 玩家进入时情绪平稳

- 正常节奏推进。
- 提供多样化选择，鼓励探索不同人生路径。
- 在关键节点引入价值观澄清。

### 3.3 玩家进入时情绪积极

- 可适当增加挑战深度。
- 高光事件后引导感恩与利他行为。
- 防止过度冒险，提供"可持续成长"选项。

## 四、CBT 技术在游戏中的具体实现

### 4.1 认知重构小游戏

在重大挫折后，弹出"你的想法是？"：
- "这都是我的错"（过度自责）
- "情况很糟，但我可以应对一部分"（现实思维）
- "这只是暂时的困难"（去灾难化）

玩家选择后，AI 根据选择续写故事，并强化对应思维模式。

### 4.2 情绪温度计

每轮事件后，让玩家用 1~10 分评估角色情绪。
- 连续低分时触发"关怀事件"。
- 结局展示情绪波动曲线，帮助玩家理解人生起伏的正常性。

### 4.3 行为实验

设计"尝试一件让你紧张的小事"事件：
- 玩家选择是否尝试。
- 结果不一定成功，但都会提升勇气属性。
- 提示："行为改变常常先于信念改变。"

### 4.4 优点记录

在结局或关键节点，展示 AI 总结的"这场人生中你展现的优点"：
- 坚持、勇气、善良、创造力、幽默感等。
- 引导玩家将这些优点与现实自我连接。

## 五、意义提升路径

### 5.1 三层意义设计

| 层次 | 说明 | 游戏事件示例 |
|---|---|---|
| 创造 | 通过工作、创作、发明创造价值 | 出版小说、创办公司、科研突破 |
| 体验 | 体验爱、美、自然、关系 | 恋爱、旅行、看一场日落 |
| 态度 | 面对不可避免痛苦时的选择 | 患病后的乐观、失败后的坚持 |

### 5.2 意义锚点

在人生早期让玩家选择 1~3 个价值观锚点：
- 家庭、自由、知识、正义、艺术、健康、友谊、财富等。
- 后续事件若符合锚点，额外提升意义感与心理韧性。

### 5.3 临终回顾

结局模拟"躺在病床上回顾一生"：
- 不是问你有多少钱，而是问：
  - "你爱过谁？"
  - "你被谁爱过？"
  - "你为何感到骄傲？"
  - "如果有机会，你想对年轻的自己说什么？"

## 六、心理健康安全边界

### 6.1 必须避免的内容

- 详细描述自伤、自杀行为。
- 鼓励孤立、仇恨、报复。
- 将失败完全归因于个人缺陷。
- 暗示"只有成功才有价值"。
- 涉及真实精神疾病的不准确刻板印象。

### 6.2 必须包含的机制

- 开场心理健康声明。
- 全程可见的"暂停/退出"入口。
- 连续低谷后的强制"喘息事件"。
- 结局强调多元价值与成长。
- 专业求助资源链接（国内：心理援助热线；国际：当地危机热线）。

### 6.3 内容审核流程

1. 设计阶段：心理学家/咨询师审核事件文案。
2. AI 阶段：System Prompt 中嵌入安全约束。
3. 运行阶段：对 AI 生成内容进行关键词与语义过滤。
4. 反馈阶段：收集玩家不适报告，建立黑名单事件库。

## 七、可量化的意义与成长指标

### 7.1 游戏内指标

- **PERMA 五维得分**：结局雷达图展示。
- **心理韧性曲线**：反映从低谷中恢复的能力。
- **价值观一致性得分**：选择符合早期价值观锚点的比例。
- **成长型思维指数**：玩家选择认知重构选项的频率。
- **社会连接度**：关系事件的参与深度。

### 7.2 玩家自评指标

结局后邀请玩家回答（可选、匿名）：
1. 玩完后，我对自己的生活多了一些希望感。（1~7 分）
2. 我意识到人生挫折可以被重新理解。（1~7 分）
3. 我愿意在现实生活中尝试一个小改变。（1~7 分）
4. 我感受到了被理解和接纳。（1~7 分）

### 7.3 迭代依据

- 以上得分用于优化事件库、Prompt、数值平衡。
- 定期 A/B 测试不同文案对玩家情绪的影响。

## 八、给开发者的实施清单

- [ ] 每个事件都标注其促进的 PERMA 维度。
- [ ] 每个低谷事件都至少包含一个成长型或接纳型选项。
- [ ] 每个高光事件都连接前期努力，并提供利他/感恩选项。
- [ ] 重大挫折后嵌入 CBT 认知重构选择。
- [ ] 结局报告包含：人生成就 + 心理成长 + 价值观一致性 + 对现实生活的启发。
- [ ] AI Prompt 中明确禁止极端负面、自伤、仇恨内容。
- [ ] 游戏中始终提供暂停、退出、求助资源入口。
- [ ] 收集匿名反馈，持续优化心理安全性。

## 九、结语

人生模拟器的终极目标不是让玩家逃避现实，而是在安全的虚拟空间中练习选择、理解情绪、重构认知、发现意义。当玩家关闭游戏时，我们希望他们带走的不只是一个有趣的故事，还有一点点面对真实人生的勇气、希望与智慧。

## 十、实现对照（2026-11）

已落地：

- PERMA 五维、心理韧性、情绪标签、感恩日志
- 六类选项类型与成长出口校验
- 低谷 → 顿悟 → 密集低谷 → 喘息的心理急救链路
- PHQ-9 / GAD-7 自愿自评与分级风险支持（含危机资源界面）
- 结局的品质选择、多元价值叙事与人生之书回看/导出

尚未落地（保留为后续方向）：

- 情绪温度计与韧性曲线可视化
- 价值观锚点系统
- 结局后匿名自评问卷
- AI 总结的「优点识别」
