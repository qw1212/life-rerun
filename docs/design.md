# 人生模拟器：游戏机制与心理设计文档

## 一、项目定位

本游戏不仅是娱乐向的人生模拟器，更是一款结合 **AI 动态叙事、积极心理学、叙事疗法** 的互动体验产品。目标是在保证"爽文"起伏感的同时，让玩家在虚拟人生中练习选择、觉察情绪、重构挫折意义，最终获得正向心理反馈。

> **边界声明**：本产品是心理自助与娱乐工具，不具备诊断或治疗功能。严重心理问题需寻求专业帮助。

## 二、可玩性优化设计

### 2.1 选择系统的深度

- **每轮 3~4 个选项**：不只分"好坏"，而是代表不同价值观：
  - 稳妥型（风险低、收益稳）
  - 冒险型（高风险高回报）
  - 关系型（提升人际与魅力）
  - 成长型（短期吃亏、长期增益）
- **隐藏选项**：当某项属性或天赋达到条件时，解锁特殊选择。
- **连续选择影响剧情分支**：早期选择会开启不同人生主线（学术、创业、艺术、社会服务等）。

### 2.2 事件节奏设计

| 阶段 | 年龄 | 节奏 | 核心体验 |
|---|---|---|---|
| 童年 | 0-12 | 快速推进 | 建立基础属性与家庭关系 |
| 青少年 | 13-18 | 中等 | 学业、友谊、自我认同 |
| 青年 | 19-35 | 较慢 | 职业、爱情、重大人生转折 |
| 中年 | 36-55 | 中等 | 事业稳定、家庭责任、中年危机 |
| 老年 | 56+ | 快速 | 回顾、传承、和解 |

### 2.3 爽文与成长并存

- **高光事件**：逆袭成功、被贵人赏识、创造非凡成就。
- **打脸事件**：曾经的否定者最终认可你，但强调内在成长而非单纯报复。
- **顿悟事件**：低谷之后触发，将失败重新定义为学习机会，提升心理韧性。
- **贵人系统**：在关键时刻出现导师/朋友/伴侣，提供帮助或启发。

### 2.4 随机性与掌控感平衡

- 属性影响事件概率，而非完全随机。
- 关键节点由玩家主动选择，避免"被剧情推着走"。
- 提供"人生预览"：选择前显示该选项可能带来的属性趋势（模糊提示）。

## 三、AI 自动生成故事机制

### 3.1 AI 使用场景

1. **事件文本润色**：根据玩家状态、属性、历史事件，生成个性化的段落。
2. **选项生成**：在关键节点由 AI 提供 3~4 个符合情境的选项。
3. **结局总结**：生成富有文学性的人生回顾与心理成长报告。
4. **顿悟对话**：在低谷事件后，AI 以"内心导师"身份提供积极心理引导。

### 3.2 Prompt 工程原则

- **结构化输入**：包含玩家属性、年龄、近期事件、当前情绪标签、人生主题。
- **输出格式约束**：要求 AI 返回 JSON，包含 `story`、`options`、`psychologyHint`、`attributeChanges`。
- **价值观约束**：在 system prompt 中明确要求积极、成长型、非暴力、尊重多元。
- **缓存机制**：相似状态下复用已生成的故事片段，降低成本与延迟。

### 3.3 示例 Prompt 结构

```text
你是一位温暖的人生叙事者。请根据以下玩家状态，续写一段人生故事，并提供 3 个选择。

玩家状态：
- 年龄：22
- 属性：智力 75，体质 60，魅力 80，家境 45，运气 55，心理韧性 70
- 当前情绪标签：焦虑但期待
- 人生主题：从小镇青年到大城市打拼
- 近期事件：高考失利后复读一年，考上普通大学；家庭经济拮据

要求：
1. 故事 150~250 字，有画面感，符合爽文节奏。
2. 选项应体现不同应对方式，并有明确的属性影响。
3. 在故事后给出一句 20 字以内的积极心理提示。
4. 返回 JSON 格式。
```

### 3.4 成本控制策略

- 80% 的常见事件使用模板 + AI 润色（轻量模型）。
- 20% 的关键节点使用强模型生成高质量故事。
- 用户本地缓存生成结果，避免重复请求。

## 四、积极心理学与叙事疗法融合

### 4.1 PERMA 模型映射

| PERMA 维度 | 游戏设计 |
|---|---|
| 积极情绪 Positive | 高光事件、感恩练习、成就庆祝 |
| 投入 Engagement | 心流事件（专注学习、创作、运动） |
| 人际关系 Relationships | 友情、爱情、家庭关系事件 |
| 意义 Meaning | 志愿服务、传承、人生使命事件 |
| 成就 Achievement | 目标达成、克服困难、技能提升 |

### 4.2 叙事疗法技术应用

- **外化问题**：将挫折描述为"暂时的客人"，而非玩家本人的定义。
- **重写故事**：结局时让玩家选择"如果重来，你最想保留哪个品质"，强化自我认同。
- **独特结果**：在低谷中强调玩家曾经的勇敢选择，寻找例外经验。

### 4.3 正向引导机制

- **选择后反馈**：每个选择都附带一句成长型提示，例如：
  - "你选择坚持，这本身就是勇气的证明。"
  - "失败不是终点，而是信息的反馈。"
- **心理韧性槽**：遭遇挫折时损失的是"情境值"而非"自我价值"，韧性越高恢复越快。
- **感恩日志**：每轮结束后玩家可写下 1~3 件值得感恩的事（可选），AI 可引用其中内容。

### 4.4 安全与伦理

- 禁用自伤、暴力、歧视等敏感内容，通过 prompt 与内容审核双重过滤。
- 连续负面事件后强制插入"喘息事件"或"支持事件"。
- 结局报告避免单一成功标准，强调多元人生价值。

## 五、用户旅程

1. **进入游戏**：欢迎语 + 心理安全提示。
2. **创建角色**：选择/抽取天赋、分配属性、匿名心情打卡。
3. **心理热身**：30 秒呼吸或一句积极 affirmations。
4. **人生推进**：事件 → 选择 → AI 续写 → 属性变化 → 心理提示。
5. **顿悟时刻**：重大挫折后触发，玩家选择如何理解这段经历。
6. **结局**：人生成就 + 心理成长报告 + 可保存的"人生之书"。
7. **回访**：玩家可回顾自己的人生故事，或重新开始。

## 六、成功指标

- 玩家完成一次完整人生的比例 > 60%。
- 玩家主动写下反思/感恩内容的比例 > 30%。
- 玩家评价"感到被理解/鼓舞"的比例 > 70%。
- AI 生成内容的满意度 > 80%。
